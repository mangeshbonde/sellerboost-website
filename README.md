# SellerBoost – OptiListing Pro

A React single-page website for product listing optimization services across Amazon, Flipkart, and Meesho.

## Tech stack

- React 18
- TypeScript / TSX
- Vite
- Tailwind CSS
- Lucide React

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

Vite outputs the production site to `dist/`. No server-side environment variables are currently required. The WhatsApp contact link is configured in `src/App.tsx`.
